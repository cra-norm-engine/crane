Compliance core

Product registry

The central inventory. Track every product with its versions, releases and assigned support period. See Core Concepts for the underlying model.

CRA Annex I matrix

A requirement coverage map per product. Each Annex I essential requirement is listed with its status and links to the evidence that satisfies it — so a coverage gap is visible immediately rather than discovered during assessment.

Technical documentation

One-click export of the documentation package needed for conformity assessment and CE marking, assembled from the evidence already in CRANE.

Security engineering

SBOM analysis

Ingest CycloneDX SBOMs with quality scoring, CRA validation, NTIA minimum-elements checks and a diff view between versions.

Vulnerability management

A PSIRT workflow over your component inventory: CVE tracking, EPSS-based prioritisation and VEX assessments that record whether each CVE actually affects a product.

Risk assessments

STRIDE, TARA or a custom methodology, each with a review-and-approval workflow so assessments can be required by release gates.

Release gates

Configurable, evidence-backed readiness checklists that must pass before a release ships.

Security operations

Beyond shipping, the CRA imposes ongoing duties. CRANE's security operations cover the post-market side:

Advisories

Publish security advisories tied to affected products and releases.

CVD policies

Publish a coordinated vulnerability disclosure policy so researchers know how to report responsibly.

Update history

A record of security updates issued per product, with timestamps.

Report triage

Intake and triage of incoming vulnerability reports from external parties.

Lifecycle & change

Substantial changes

Assess whether a change is "substantial" under the CRA and track the re-conformity work it triggers. See CRA Context.

Lifecycle alerts

End-of-support monitoring with configurable thresholds, so support-period obligations are surfaced before they lapse.

Audit trail

An immutable, timestamped log of every action taken in the platform — the foundation of CRANE's traceability.

Collaboration & access

Task management

Work from a Jira-style board with Backlog, In progress and Done / release columns. Drag assigned manual tasks between columns, link parent tasks and subtasks, add comments, retain completion history and archive finished work without losing its audit trail. Assignment is governed by the selectable task_assign role permission.

Jira Cloud

Connect Jira Cloud with OAuth 2.0, choose the destination project and issue type, map CRANE statuses and priorities, map assignees to Atlassian account IDs, export tasks, and synchronize the entire CRANE board or individual issues. Jira-linked tasks also support a Forge issue panel.

Team collaboration

A multi-user platform with task assignment and commenting, so compliance work is shared rather than siloed.

RBAC + LDAP

Role-based access control with optional Active Directory / OpenLDAP integration for enterprise environments. See Configuration for setup.
