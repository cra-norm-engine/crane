FAQ & Troubleshooting

Quick answers to the questions that come up most often, and fixes for the issues you're most likely to hit during install and first run.

General

Is CRANE production-ready?

CRANE is in active development and used in real compliance engagements. Core modules are stable, but some advanced features are still evolving. It is not yet recommended for fully unattended production use without technical oversight — run it with someone who can keep an eye on updates and backups.

What does it cost?

Nothing. CRANE is free and open source under AGPL-3.0. There are no per-seat or per-client licensing fees — which is why consultants can run one instance per client at no marginal cost.

What does AGPL-3.0 mean for me?

You can use, audit, fork and extend CRANE freely. The key obligation: if you modify CRANE and offer it to others over a network, you must make your modified source available under the same licence. For internal self-hosted use, you simply run it — no obligations triggered.

Can I use CRANE commercially?

Yes. Using CRANE to support your commercial compliance programme is unrestricted. Consultants can run it for clients without per-client fees. The AGPL restriction only applies if you modify CRANE and offer it as a service to others.

Where does my data go?

Nowhere you don't control. All data stays in your own PostgreSQL instance, with no telemetry, no callbacks and no external dependencies at runtime. You can export your full dataset at any time.

Which SBOM format does CRANE accept?

CycloneDX (JSON, versions 1.4–1.6). CRANE scores SBOM quality, validates CRA Phase 2 requirements and checks NTIA minimum elements, and can diff two SBOM versions. SPDX import is on the roadmap.

Do I have to run Trivy?

No. Trivy is optional. CRANE uses OSV and NVD data with EPSS scoring out of the box; Trivy adds deeper OS-level and container scanning if you enable it. The Trivy binary is pre-installed in the Docker image but only activated when you submit an SBOM for scanning.

Does CRANE replace a Notified Body assessment?

No. CRANE organises and evidences your compliance work. Whether you need a Notified Body depends on your product classification under the CRA. For default-class products, a manufacturer self-assessment supported by CRANE's evidence is the expected route. For Important Class II products, a third-party Notified Body assessment is mandatory regardless of tooling.

Is CRANE an official EU compliance tool?

No. CRANE is an independent open-source project with no affiliation to the European Commission, ENISA, or any standards body. It is built to reflect the regulation as written, but always verify against official guidance.

Installation & first run

The first start is taking several minutes — is it stuck?

Almost certainly not. The first run takes 3–5 minutes while Docker builds the backend image and downloads the Trivy vulnerability database. Watch progress with:

docker compose logs -f

A port is already in use

If something else is already bound to 5173 or 8000, edit the host ports in your .env and restart. Check what's using a port with:

lsof -i :5173        # macOS / Linux
netstat -ano | findstr :5173   # Windows

Windows: containers fail to start

Make sure Docker Desktop is set to Linux containers — right-click the Docker tray icon and switch if needed. CRANE's images are Linux-based and will not start in Windows containers mode.

The install script was blocked by my security policy

Some organisations block curl | bash patterns. Use the manual installation instead: download the ZIP from GitHub, extract it, copy .env.example to .env, set your secrets, and run docker compose up -d. See Manual installation.

I can't log in / forgot the admin password

The default credentials are admin@example.com / admin1234, and you're prompted to change the password on first login. If you've lost access, reset it directly in the database:

# Generate a new bcrypt hash for your new password first
# Then update the record:
docker compose exec postgres psql -U postgres -d cra_compliance \
  -c "UPDATE users SET hashed_password='<new_hash>' WHERE email='admin@example.com';"

How do I update to a newer version?

git pull
docker compose up -d --build

Database migrations are handled by Alembic on startup — no manual steps needed. Back up first — see Backups.

How do I completely reset my instance?

This deletes all data

docker compose down -v removes the volumes, including your PostgreSQL database. Export or back up first if you need the data.

Using the platform

How should consultants isolate client data?

Run one instance per client, each in its own directory with its own .env and database volume. See Running multiple isolated instances.

Can I use CRANE for training courses or university exercises?

Yes — this is explicitly supported and costs nothing. Spin up a shared instance, create student accounts with scoped roles, and let each team build out a fictional product through the full compliance lifecycle. The audit log makes reviewing student work straightforward.

How do I create additional users?

Log in as admin, go to Administration → Users, and invite new users by email. Assign them a role that reflects their access level. With LDAP enabled, users can also be provisioned automatically on first login.

What roles are available by default?

RoleTypical user
AdminPlatform administrator — full access
Product OwnerResponsible for product compliance
Cybersecurity EngineerVulnerability management, risk assessments
Development TeamSBOM uploads, release management
Legal TeamRead-only access for compliance review
Lifecycle ManagerSupport periods, end-of-life management

Roles can be customised with granular permissions in Administration → Roles.

Can I integrate CRANE with my CI pipeline or issue tracker?

You can drive everything through the REST API today — upload SBOMs, trigger scans, query vulnerability status. Native GitHub / GitLab and Jira integrations are on the roadmap.

How do I export data for a Notified Body?

Use the Technical Documentation export from the product or release detail page. This assembles the evidence package from your SBOM, risk assessment, vulnerability records, and Annex I coverage map in one step. For raw data portability, use the full data export from Administration.
